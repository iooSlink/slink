# Slink downloads

Download Slink apps and builds from the [v1.1.0 release](https://github.com/iooSlink/slink-downloads/releases/tag/v1.1.0).

This repository contains public release files and a download page only; the Slink source code is kept separately.

- Android: [Slink.apk](https://github.com/iooSlink/slink-downloads/releases/download/v1.1.0/Slink.apk)
- Windows: [Slink-windows-x64.zip](https://github.com/iooSlink/slink-downloads/releases/download/v1.1.0/Slink-windows-x64.zip)
- macOS: [Slink-macos-universal.zip](https://github.com/iooSlink/slink-downloads/releases/download/v1.1.0/Slink-macos-universal.zip)
- Linux: [Slink-linux-x86_64.tar.gz](https://github.com/iooSlink/slink-downloads/releases/download/v1.1.0/Slink-linux-x86_64.tar.gz)
- iOS (unsigned): [Slink-ios-unsigned.ipa](https://github.com/iooSlink/slink-downloads/releases/download/v1.1.0/Slink-ios-unsigned.ipa)
- Browser build: [Slink-web.zip](https://github.com/iooSlink/slink-downloads/releases/download/v1.1.0/Slink-web.zip)
